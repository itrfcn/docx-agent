CA6140 普通车床安全操作规程 SOP
========================================

一、上岗前准备
------------------------------
1. 穿戴好工作服、防护眼镜，严禁戴手套操作旋转机床。
2. 检查机床各手柄位置是否正确，主轴变速手柄必须停在空档。
3. 检查卡盘夹紧力，确保工件装夹牢固，悬伸长度不超过直径的 4 倍。
4. 检查润滑系统，各油孔油量充足，油标显示正常。

二、启动与操作
------------------------------
1. 先启动润滑油泵，运转 2 分钟后再启动主轴。
2. 主轴转速选择：粗车钢件不超过 600 rpm，精车不超过 1200 rpm，车削铸铁不超过 800 rpm。
3. 进给量选择：粗车 0.3~0.8mm/r，精车 0.05~0.2mm/r。
4. 车削过程中禁止用手触摸旋转工件，禁止用棉纱擦拭工件。
5. 测量工件必须停车，停车时不得用手制动卡盘。

三、停车与清理
------------------------------
1. 加工结束后，将各手柄移至空档，关闭电源。
2. 清理铁屑必须用钩子，严禁用手直接清理。
3. 擦拭机床，导轨面涂油防锈。
4. 填写设备运行记录，记录加工件数、材质、有无异常。

四、应急处理
------------------------------
1. 发生卡盘松动、工件飞出等危险情况，立即按下急停按钮。
2. 铁屑卷入工件时立即停车，严禁在旋转时拉扯。
3. 电气故障由电工处理，机械故障由维修工处理，操作工不得擅自拆修。
