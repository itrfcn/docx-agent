IT 设备申领与故障报修流程

一、适用范围
本流程适用于公司员工办公电脑、显示器、键鼠外设、打印机、网络设备及软件账号的申领、报修与归还。

二、设备申领
1. 新员工入职时，由人力资源部在 OA 发起《IT 设备申领单》，注明岗位、办公地点与设备需求。
2. 在职员工因岗位调整或设备损坏需新增设备的，须由部门负责人在 OA 审批后提交 IT 部。
3. IT 部在收到审批完成的申领单后 3 个工作日内完成配置并通知领取。
4. 领取时须在《设备领用登记表》签字确认，设备纳入个人资产台账。

三、故障报修
1. 报修渠道：IT 服务台电话 8000（内线）或邮箱 it-support@company.com；紧急故障可直接到 3 楼 IT 服务台。
2. 响应时效：工作时间内 30 分钟内远程响应；无法远程解决的，4 小时内到场处理。
3. 报修时请提供：设备资产编号、故障现象、发生时间及已尝试的处理方式。
4. 设备送修期间，IT 部可提供备用机，备用机使用期限一般不超过 5 个工作日。

四、账号与软件
1. 系统账号开通须由用人部门负责人在 OA 提交《账号权限申请单》，经信息安全负责人审批。
2. 商业软件安装须使用公司统一采购的授权版本，禁止安装未授权的破解软件。
3. 离职员工账号由 IT 部在离职当日停用，相关权限同步回收。

五、设备归还
1. 员工离职或调岗时，须将设备及配件完整归还 IT 部，并删除个人数据。
2. 设备丢失或人为损坏的，按资产折旧后的残值赔偿。

六、其他
1. 严禁私自拆装办公设备，由此造成的损坏由个人承担维修费用。
2. 本流程由信息技术部负责解释。
